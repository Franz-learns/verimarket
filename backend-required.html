What works here?

Navigation, marketplace search, listing detail links, responsive layouts, mobile navigation and the original animations run in the browser.

Why are forms disabled?

The original forms depend on PHP sessions, uploads and a SQLite database. GitHub Pages hosts static files, so those operations need a separately hosted backend. Fields are disabled here to keep a layout preview from appearing to accept real passwords or identity documents.

About the example content

All listings, account names and conversations are illustrative. The original design’s statistics and testimonials are sample content; some feature claims describe planned capabilities. Those sections carry labels. The original ZIP’s database, admin configuration and uploaded documents are excluded.
